# 初中物理知识图谱数据说明

`junior_physics_2024.json` 是我从初中物理教材中抽取并整理的知识图谱数据。我先使用 MinerU 将 PDF 教材解析为 Markdown，再借助大语言模型提取知识实体与关系，对结果进行清洗、去重和实体 ID 统一，整理成可导入 Neo4j 的 JSON。

为了支持题目知识点到教材章节的定位，我又参考人教版 2024 年教材目录，补充年级信息、册别、章、节及知识实体到章节的归属关系。当前文件含 436 个实体、788 条关系；其中 117 个是教材目录节点，319 个是知识实体。目录节点用于章节定位，不参与题目向量检索。

`TAUGHT_IN` 连接知识实体与节，`COVERED_IN_CHAPTER` 连接知识实体与章，`BELONGS_TO` 连接节、章和册别。

JSON 的 `entities` 保存实体，`edges` 保存有方向的关系；实体原 ID 在导入 Neo4j 时加上 `junior_physics:` 前缀。
